# Hi, I'm Omkar Shende

**AI Systems Research Engineer | Efficient Inference, Runtime Optimization, and Edge AI on Heterogeneous Accelerators**

I build AI systems for **efficient, adaptive, and deployment-ready inference on heterogeneous edge platforms**. My work spans benchmarking, profiling, runtime optimization, scheduling, and cost-aware execution across real hardware and software stacks.

My focus is on turning systems ideas into **practical research-engineering artifacts** that look and feel closer to deployable inference infrastructure than paper-only repositories.

Worked across heterogeneous inference pipelines spanning **GPU, NPU, DLA, and CPU-backed edge systems**, with emphasis on real deployment tradeoffs rather than theoretical accelerator capability.

## What I work on

- **Benchmarking heterogeneous edge platforms** across CPU, GPU, NPU, DLA, and VPU-class accelerators
- **Profiling end-to-end inference behavior** beyond vendor TOPS claims
- **Comparing runtimes and deployment stacks** for real-world edge workloads
- **Designing scheduling strategies** for concurrent DNN execution under resource contention
- **Building adaptive inference systems** that route inputs based on cost/performance tradeoffs
- **Evaluating deployment metrics** including latency, throughput, power, thermal behavior, and cost-effectiveness
